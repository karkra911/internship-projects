# AI Spend Audit

## Overview
A web application that analyzes AI tool spending and recommends cost optimizations.

## Features
- AI spend analysis
- Savings recommendations
- Shareable reports
- Email capture

## Tech Stack
- Next.js
- TypeScript
- Tailwind
- Supabase

## Run Locally
npm install
npm run dev

## Deployment
https://your-app.vercel.app

## Decisions
- Used rule-based audit engine instead of AI for pricing reliability
- Used localStorage for persistence
